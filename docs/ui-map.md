## Conventions

- **Theme** is `goyo-theme` in `localStorage` (`contexts/ThemeContext.tsx`).
- **Dialog request** is one value in `lib/dialogLauncher.ts`; `components/dialogs/registry.tsx` maps it to the mounted dialog. A new dashboard entry point adds one request kind, not a show boolean.
- **Screenshots**: `pnpm shots` captures the main screens above in light and dark at desktop and iPhone sizes into `.tmp/shots/current/`. Use `SHOTS_LABEL=before` / `SHOTS_LABEL=after` to compare, or `SHOTS_BASE_URL` to reuse a running server.
